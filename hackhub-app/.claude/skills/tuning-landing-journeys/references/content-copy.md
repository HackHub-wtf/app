# Content Copy

## When to use
When writing or revising headline copy, button labels, empty states, or value proposition text on Home, Login, or Hackathons pages.

## Patterns

**Headline → value prop → CTA stack**
Order copy so each line answers the next question: "What is this?" → "Why should I care?" → "What do I do?". Use `Title order={1}` for the headline, `Text c="dimmed"` for the value prop, and a verb-led button label for the CTA.

**Verb-led button labels**
Labels like "Browse hackathons", "Join now", and "Start your team" outperform "Learn more" or "Get started" because they describe the outcome. Match the label to the destination route.

**Social proof copy near CTAs**
Counts ("42 active hackathons", "1,200 participants") placed immediately above or below the primary CTA reinforce the decision. Keep them factual and current — stale numbers hurt trust.

## Pitfalls
- Avoid vague superlatives ("best", "powerful", "seamless"). They consume space without communicating value. Replace with a specific outcome the user gets.
