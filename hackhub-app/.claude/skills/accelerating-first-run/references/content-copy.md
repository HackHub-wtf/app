# Content Copy

## When to use
When writing or auditing the text inside onboarding flows, empty states, tooltips, and CTAs — anywhere copy directly affects whether a new user takes the next step.

## Patterns

**Action-first button labels**
Use verb + object: "Create a team", "Browse hackathons", "Submit your idea". Avoid generic labels like "Continue", "Next", or "OK" that don't communicate what happens.

**Empty state copy that answers "why bother"**
Empty states should do two things: explain what the user gets from taking action, and tell them exactly how to start. Example: "No teams yet — form one to collaborate with others and submit a shared idea." followed by a single button.

**Tooltip copy scoped to the current moment**
Contextual tooltips should reference the user's current state, not generic product features. "You haven't joined a hackathon yet — this is where active events will appear" beats "View your hackathons here".

## Pitfalls
- Avoid copy that assumes the user already understands HackHub's model (e.g., "Your hackathon workspace"). New users don't have that mental model yet. Write for someone who signed up 30 seconds ago.
